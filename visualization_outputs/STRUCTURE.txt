================================================================================
NAMING CONVENTIONS
================================================================================

Confusion Matrices (individual/):
  Format: {dataset}_{model}.png
  Example: iml_lifecycle_efficientnet_b1.png

Training Curves:
  Format: {metric}_{dataset}.png
  Example: accuracy_iml_lifecycle.png

Test Visualizations (full/):
  Format: {model}_{dataset}/
  Example: yolo11_iml_lifecycle/
           efficientnet_b1_iml_lifecycle/

Selected Cases:
  Simple: detection/ and classification/ folders
  Files numbered by error severity (highest first)

KEY FEATURES

  python scripts/visualization/regenerate_publication_quality_confusion_matrices.py
