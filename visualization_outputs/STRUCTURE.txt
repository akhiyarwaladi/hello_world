===================================================================================
FOLDER PURPOSES
===================================================================================

[confusion_matrices/]
- Publication-quality confusion matrices
- Individual matrices per dataset-model combination
- Covers top-performing models (EfficientNet-B0/B1/B2, ResNet50/101)

[training_curves/]
- Training progress visualization
- Accuracy and loss curves per dataset
- Shows convergence behavior and overfitting analysis

[selected_cases/]
- FINAL CURATED CASES for publication (6 detection + 6 classification)
- Based on FIGURE_METADATA_MAPPING.md criteria
- Represents 6 error types each: Simple FP, Pure FN, Heavy FP, Mixed,
  Crowded field, Atypical FN (detection); Single error 66.7%, Moderate 50%,
  Stage transition, Species confusion, Heavy error, Perfect crowded (classification)

[report_examples/]
- Specific example images referenced in Laporan_Akhir_Penelitian.md
- Detection example: 1409171742-0009-R (6 parasites, 77.1% conf)
- Classification example: PA171852 (66.7% accuracy, realistic performance)

[full/]
- Complete test set visualizations for best models only
- YOLO11 (detection) - 96.61% mAP@50
- EfficientNet-B1 Focal (classification) - 90% accuracy
- 672 total images = 336 detection + 336 classification

[metadata/]
- CSV files with comprehensive metadata for all error cases
- Includes: image names, GT boxes, predictions, accuracy, confidence, status
- Used for selecting publication figures and analysis

===================================================================================
GENERATION SCRIPTS
===================================================================================

Main generator:
  scripts/visualization/generate_all_centralized.py
  - Generates confusion matrices, training curves, selected error cases
  - Auto-detects latest experiment folder
  - Output: visualization_outputs/

Supporting scripts:
  scripts/visualization/copy_best_visualizations.py
  - Copies best model visualizations (YOLO11 + EfficientNet-B1) to full/

  scripts/visualization/generate_all_centralized.py --bbox-predictions-only
  - Regenerates only selected error cases

Usage:
  # Generate everything
  python scripts/visualization/generate_all_centralized.py

  # Regenerate confusion matrices only
  python scripts/visualization/generate_all_centralized.py --confusion-matrices-only

  # Copy full best model visualizations
  python scripts/visualization/copy_best_visualizations.py
