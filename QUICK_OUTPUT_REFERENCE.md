## ⚠️ COMMON ISSUES

### Issue: "consolidated_analysis/ folder is empty"
**Cause**: Only generated for multi-dataset runs (`--dataset all`)
**Solution**: Run with `--dataset all` or use individual dataset results

### Issue: "Can't find table9_classification_pivot.xlsx"
**Location**: `results/optA_*/experiments/experiment_{dataset}/table9_classification_pivot.xlsx`
**Note**: One file per dataset

### Issue: "Manual figures not generated"
**Cause**: Scripts in `scripts/visualization/` must be run manually
**Solution**: Run scripts individually (see "WHAT TO RUN MANUALLY" section)

### Issue: "Archived script not found"
**Script**: `generate_comprehensive_consolidated_analysis.py`
**Location**: Currently in `archive/figure_generators/`
**Solution**: Restore from archive or pipeline will skip consolidated analysis

## 🚀 PRO TIPS

1. **Always check ZIP file**: The ZIP contains everything you need
2. **Excel files are publication-ready**: Open directly in Word/Excel
3. **PNG files are 300 DPI**: Suitable for publication
4. **table9_metrics.json is critical**: Don't delete, used for analysis
5. **best.pt is the final model**: Use for predictions, not last.pt
6. **Manual scripts can run anytime**: Don't need pipeline to complete
